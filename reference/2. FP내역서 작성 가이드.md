## FP 수정사항



하기에 명시한 셀만 수정하도록 함.  





C3 : SR NO  
C5 : 모듈 - 프로그램명 체크하여 작성. 'Z' 뒤의 알파벳 두 개가 모듈임. 예시로 ZCOBC1180인 경우 모듈은 'CO'  
C6 : 작성자 - SR 세부내역에서 SPEC 분류의 관리자로 지정된 사람을 입력
C7 : 작성일자 - 오늘날짜  
B12\~B31 : 수정한 프로그램  /
C12\~C31 : 수정한 프로그램명  
D12\~D31 : 화면기능 중 입력 기능을 수정한 경우 1, 아니면 0  
E12\~E31 : 화면기능 중 수정 기능을 수정한 경우 1, 아니면 0
F12\~F31 : 화면기능 중 삭제 기능을 수정한 경우 1, 아니면 0
G12\~G31 : 외부와 연동되는 Function을 수정한 경우(데이터송신) 1, 아니면 0
H12\~H31 : 외부와 연동되는 Function을 수정한 경우(데이터수신) 1, 아니면 0
K12 : 계산식이 적용된 R27에 3 이상이 나오도록 입력  



필수사항:  

* 참고 템플릿 문서를 수정하지 말고 항상 복사본을 만들어 수정할 것



금지사항 :  

* 위의 수정사항 이외의 계산식 및 열너비, 셀병합 등의 레이아웃은 절대 변경 금지
