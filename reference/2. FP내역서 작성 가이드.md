## 작성원칙
- 'template\FP_v4.4_SRM26080752972_20260807 FM.xlsx' 템플릿을 참고하여 작성.
- 파일명은 'FP_v4.4_{SR NO}_{현재일자} {모듈명}.xlsx'으로 할 것
- 수정 세부 사항에 명시한 셀만 수정하도록 함.
- 입력자료
  - SR 상세 : SR 분석가가 정리한 SR 요약본을 우선 활용, 없는 경우 ITSM SR 상세를 직접 조회하여 작성
  - 수정 로직 : ABAP 소스분석가가 zdown 수정 전 · 후 소스를 비교하여 작성한 수정 로직 html — K12
    변경율 산정의 근거로 사용
- 수정 전 · 후 zdown 비교 결과(수정 로직 html)가 없으면 K12 변경율을 산정할 수 없으므로 작성 진행 불가

### 필수사항
- 템플릿 문서는 항상 복사본을 만들어 수정할 것

### 금지사항
- 위의 수정사항 이외의 계산식 및 열너비, 셀병합 등의 레이아웃 절대 변경 금지  

## 수정 세부 사항
- C3 : SR NO  
- C5 : 모듈 - 프로그램명 체크하여 작성. 'Z' 뒤의 알파벳 두 글자가 모듈명
  예시로 ZCOBC1180인 경우 모듈은 'CO'  
- C6 : 작성자 - SR 상세 > SR 분기 현황 > 담당자로 지정된 사람을 입력
- C7 : 작성일자 - 현재일자
- B12:B31 : 수정한 프로그램
- C12:C31 : 수정한 프로그램명  
- D12:D31 : 화면기능 중 입력 기능을 수정한 경우 1, 아니면 0  
- E12:E31 : 화면기능 중 수정 기능을 수정한 경우 1, 아니면 0
- F12:F31 : 화면기능 중 삭제 기능을 수정한 경우 1, 아니면 0
- G12:G31 : 외부와 연동되는 Function을 수정한 경우(데이터송신) 1, 아니면 0
- H12:H31 : 외부와 연동되는 Function을 수정한 경우(데이터수신) 1, 아니면 0
- K12:K31 : 변경율. 변경율에 따라서 총 공수가 산정되므로 요청사항, 실제수정내용(수정 로직 html 참고), 'FP 산정 가이드'탭을 참고하여 산정.
